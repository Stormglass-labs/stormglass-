# StormGlass

**Know your worst day before it happens.**

StormGlass builds a model of an organisation's
environment, simulates severe-but-plausible cyber
scenarios against it, and turns the outcomes into
quantified impact and control evidence.

## Modules
1. Twin builder
2. Scenario library
3. Simulation engine
4. Impact model
5. Control and evidence mapper
6. Narrative layer
7. Agent conduct lab



## Status
Early development. M.S. Cybersecurity project,
University of Delaware.
